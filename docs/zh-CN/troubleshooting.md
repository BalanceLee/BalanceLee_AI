# 故障排查

## 服务无法启动

检查配置文件路径、端口占用、Go 版本和本地工具依赖。优先查看终端输出中的第一条错误。

## 前端空白或接口失败

确认后端已启动，并使用浏览器开发者工具检查请求地址和响应状态。跨主机访问时，后端监听地址不能只绑定 `127.0.0.1`。

## Agent 没有调用工具

检查 MCP 服务是否已连接、工具是否启用、当前编排模式是否允许工具调用，以及模型是否返回了有效的工具调用参数。

## 终端连接失败

Windows 使用 ConPTY，Linux 使用 PTY。确认系统终端依赖、WebSocket 地址和后端端口可访问；反向代理需要正确转发 WebSocket Upgrade 请求。

## C2 或 WebShell 连接失败

确认监听端口未被占用，目标主机能够访问监听地址，并检查连接类型、回连地址和防火墙规则。

## 知识库检索无结果

确认知识库已启用并完成索引，查询内容包含有效关键词；修改 embedding 配置后通常需要重新建立索引。
